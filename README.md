# Kelab Teknologi Digital

Laman web rasmi bagi Kelab Teknologi Digital.

## Kandungan Laman Web
- **Utama (`index.html`):** Paparan utama dan maklumat terkini kelab.
- **Tentang Kami (`about.html`):** Latar belakang dan objektif kelab.
- **Pendaftaran & Log Masuk (`register.html` / `login.html`):** Portal keahlian.
- **Pembayaran (`payment.html`):** Urusan yuran atau sumbangan kelab.
